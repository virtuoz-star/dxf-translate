# dxf-translate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Package the working UA→EN SolidWorks-DXF translator (`~/Projects/translate/tool`) as a reusable product: Python core + CLI, Claude Code plugin with a workflow skill, PySide6 desktop app, Windows `.exe` release.

**Architecture:** One package `dxf_translate` (src layout) holds the core (glossary, Excel, translate, overlaps, review, pipeline) and a `gui` subpackage behind the optional `gui` extra. CLI, GUI and the plugin skill all call `pipeline.run_job`. The glossary moves from Python constants to bundled YAML plus an optional per-order YAML.

**Tech Stack:** Python 3.12, uv, ezdxf 1.4.5 (pinned — rendering/measuring must not drift), pymupdf, openpyxl, pyyaml, pytest; PySide6 + PyInstaller for the desktop app; GitHub Actions.

**Spec:** `docs/spec.md`

## Global Constraints

- Repo: `/home/king/Projects/dxf-translate`, private GitHub `virtuoz-star/dxf-translate`, no LICENSE file.
- Never commit customer data: `*.dxf`, `*.DXF`, `*.xlsx`, `*.pdf`, `EN/` (except files under `tests/fixtures/` generated by code — fixtures are generated at test time, not committed).

- Fonts: `OpenGostTypeA-Regular.ttf` (render + measure), `osifont.ttf` fallback, `OpenGost-LICENSE.txt` — copied unchanged from `tool/fonts`.
- Output naming unchanged: `<out>/dxf/<stem>_EN.dxf`, `<out>/pdf/<stem>_EN.pdf`, `<out>/review/index.html` + `<out>/review/crops/`. Default `<out>` = `<folder of first input DXF>/EN`.
- Report strings kept: `!! NO TRANSLATION: …`, `!! FAILED: …`, `TOTAL new overlaps: N`.
- CLI exit codes: 0 ok, 1 any file failed, 2 missing translations or overlaps (failure wins over 2).
- GUI copy is Ukrainian.
- Behaviour must stay content-identical to the prototype on the current order (Task 1 baseline).
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- File names with spaces / Cyrillic and upper-case `.DXF` (Windows users) → processed, outputs named `<stem>_EN.*`. Test in Task 5.
- Dropping a folder that already contains `EN/` or `*_EN.dxf` outputs (rerun after "save and re-run") → outputs are never re-translated as inputs; old outputs overwritten; stale review crops removed. Test in Task 5.
- A corrupt file or an unsupported sheet size among good ones → that file reported as failed, the rest translated, exit code 1. Test in Task 5.
- Hand-edited, malformed order `glossary.yaml` → `GlossaryError` naming the file (and YAML line), shown as an error in CLI/GUI, not a traceback. Test in Task 2.
- Two UA or two EN Excel files in the drop → clear "ambiguous Excel" error before any translation. Test in Task 2.

### Task 5: Pipeline and CLI

**Files:**
- Create: `src/dxf_translate/pipeline.py`, `src/dxf_translate/cli.py`, `tests/test_pipeline.py`, `tests/test_cli.py`

**Interfaces:**
- Produces:
  ```python
  @dataclass
  class MissingText: text: str; kind: str; files: list[str]
  @dataclass
  class JobResult:
      out_dir: Path; review: Path | None
      sheets: list[SheetResult]; failed: list[tuple[str, str]]   # (file name, message)
      missing: list[MissingText]                                 # deduplicated by (text, kind), sorted
      overlaps: list[Overlap]
      warnings: list[str]                                        # e.g. "Excel не знайдено" -> use code "no_excel"; text in UI layer
      excel: tuple[Path, Path] | None
      @property exit_code -> int                                 # 1 if failed else 2 if missing or overlaps else 0
  ProgressFn = Callable[[int, int, str], None]                   # (done, total, current file name)
  def collect_inputs(paths: list[Path]) -> tuple[list[Path], list[Path]]   # (dxfs, xlsxs); folders non-recursive; skips *_EN.dxf and anything inside a folder named EN; dedup by resolved path; sorted by name
  def run_job(paths: list[Path], out_dir: Path | None = None, progress: ProgressFn | None = None, review: bool = True) -> JobResult
  ```
  `run_job` order: collect → `pick_pair` (GlossaryError propagates — no partial work) → `glossary.load(order_dir)` where `order_dir` = folder of first DXF → `add_excel_pairs` → translate each (exceptions per file → `failed`) → overlaps for each produced sheet (src = its input) → review (if any sheet) → result. `ValueError("no DXF files")` when nothing to do.
- CLI: `dxf-translate PATH... [--out DIR] [--no-review] [--overlaps-only]` prints the legacy report lines, overlap lines `file: 'text' at (x, y) mm crosses n line(s)`, `TOTAL new overlaps: N`, review path, then `sys.exit(result.exit_code)`. `GlossaryError`/`ValueError` → message to stderr, exit 1. `--overlaps-only`: skip translation, check existing `<out>/dxf` against inputs.
